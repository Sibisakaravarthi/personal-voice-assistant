# Personal Voice Assistant 
The Personal Voice Assistant named “MINI” is an intelligent desktop assistant designed to streamline and automate tasks using voice commands. Built with Python and featuring a modular design, Mini provides a seamless interaction experience through dynamic visual feedback and voice-based control. Initially in an idle state, Mini displays a static image. Upon detecting wake words ("Hey Mini" or "Hello Mini"), it transitions to an active listening state by transforming the image into an animated GIF, visually signalling readiness to process commands.
Mini offers functionality such as opening applications, conducting web searches, modify system settings like set volume, set brightness etc., and engaging in advanced conversations through OpenAI integration. Persistent memory, managed through JSON-based storage, ensures user preferences and settings are remembered across sessions. The assistant's GUI, powered by PyQt5, enhances usability with intuitive and visually interactive design.
This project demonstrates the effective integration of voice recognition, dynamic visual elements, and task automation, creating a practical and engaging desktop assistant. Mini's extensible architecture makes it a powerful tool for improving productivity and intelligent system interactions.
